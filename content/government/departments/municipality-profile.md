# Carigara at a glance

Basic public facts about the Municipality of Carigara, Leyte. Every figure on
this page cites where it came from and when it was retrieved.

---

## The municipality

|                        |                               |
| ---------------------- | ----------------------------- |
| Province               | Leyte                         |
| Region                 | Region VIII — Eastern Visayas |
| Congressional district | 2nd District of Leyte         |
| Income class           | 1st class municipality        |
| Land area              | 117.86 km² (45.51 sq mi)      |
| Barangays              | 49                            |

## Population

| Census        | Population |
| ------------- | ---------- |
| 2024 (POPCEN) | 56,060     |
| 2020          | 54,656     |
| 2015          | 51,345     |

The 2015 census recorded 11,303 households, averaging 4.53 members each.

The 2024 Census of Population counts were declared official by the President.
The 2020 and 2015 figures are corroborated by two independent sources; the 2024
figure currently rests on one, and is flagged below.
